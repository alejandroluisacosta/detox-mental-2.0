🧠 Detox Mental

Detox Mental is a guided self-reflection web app designed to help users confront and reframe destructive thought patterns.
It combines structured journaling with dynamic content unlocking to build mental resilience through clarity and consistency.

🚀 Overview

This repository contains Version 1 (MVP) of the project — the core product experience, including:

- The main article introducing the Detox Mental philosophy.
- The interactive course that guides users step by step.
- The sessions system, allowing users to engage with exercises over time.
- The session-unlocking feature, progressively revealing content as users complete prior tasks.
- All built with a minimal, distraction-free interface designed for focus and introspection.

🛠️ Tech Stack

- Frontend: React + Vite
- Styling: CSS Modules / Custom CSS
- State Management: Local state + Context (no backend yet)
- Deployment: Static build (Vercel / Netlify compatible)

💾 Installation & Setup

Clone the repo and install dependencies:

git clone https://github.com/alejandroluisacosta/detox-mental-2.0.git
cd detox-mental
cd frontend
npm install


Run the development server:

npm run dev


Then open your browser at the URL shown in the terminal (usually http://localhost:5173).

Build for production:

npm run build


Preview the production build locally:

npm run preview
