# Code Review Checklist

Review the implementation for:

## Correctness

- Does it solve the requested problem?

---

## Simplicity

- Can anything be removed?

---

## Readability

- Are names clear?
- Is the code easy to follow?

---

## Duplication

- Is existing functionality being repeated?

---

## Architecture

- Does it fit the project's structure?

---

## Edge Cases

- What happens with invalid input?
- Empty states?
- Loading states?
- Error states?

---

## Accessibility

- Keyboard navigation
- Labels
- Semantic HTML

---

## Maintainability

- Would another developer understand this six months from now?
