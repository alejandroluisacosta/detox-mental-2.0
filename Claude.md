# Claude Code - Getting Started

Welcome to Claude Code! This is Anthropic's official CLI tool for interactive software development with Claude.

## What is Claude?

Claude is an AI assistant that helps with software engineering tasks including:
- Writing and editing code
- Debugging and fixing issues
- Explaining codebases
- Implementing new features
- Refactoring and optimization
- Running tests and builds

## Basic Usage

### Asking for Help
- Be specific about what you want to accomplish
- Provide context when asking about code
- Reference file paths when relevant

### Common Tasks
- "Read the file at [path] and explain what it does"
- "Help me implement [feature]"
- "Fix the bug in [file]"
- "Add tests for [functionality]"
- "Refactor [component] to [improvement]"

### Working with Files
Claude can:
- Read and analyze your code
- Edit existing files
- Create new files (when necessary)
- Search through your codebase
- Run commands and tests

### Git Operations
- "Create a commit with these changes"
- "Show me what's changed"
- "Create a pull request"

### Getting Help
- Type `/help` for CLI help
- Report issues at: https://github.com/anthropics/claude-code/issues

## Tips

1. **Be clear and specific** - The more context you provide, the better Claude can help
2. **Ask questions** - Claude can explain code, architecture decisions, and more
3. **Iterate** - Start with a basic implementation and refine as needed
4. **Review changes** - Always review code changes before committing

## Project Context

Claude maintains context throughout your conversation and can understand your codebase structure, recent changes, and project goals.
